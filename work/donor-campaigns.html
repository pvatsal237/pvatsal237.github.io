Which campaigns recruit donors who return?

A blood-donation charity spends about $600,000 a year on recruitment campaigns and judges them by cost per new donor. I rebuilt the reporting around a better question: what does each campaign pay for a donor who comes back within a year?

Data: "Northlake Donor Network" (fictional), fully synthetic, Apr 2023 – Sep 2026Scope: donations, 17 campaigns, 6 regionsTools: Power BI, DAX, SQL

Key findings

    01 · THE RIGHT MEASURE

    The cheapest donors to recruit aren't always the cheapest to keep

    Cost per new donor ranks campaigns one way. Cost per donor who returns within 12 months ranks them differently, because some campaigns attract one-time donors.

    Bring a Buddy costs per returning donor. World Blood Donor Day costs , four times as much, even though it looks reasonable on recruitment alone.

    Recommendations

    Marketing director

    Judge campaigns on cost per returning donor

    Make it the headline KPI and shift budget from awareness days toward referral and workplace campaigns.

    Measure: cost per returning donor
    Donor operations

    Send SMS reminders to every booking

    The experiment is conclusive. Roll it out, starting with first-time donors where the effect is biggest.

    Measure: no-show rate, monthly
    CRM team

    Run reactivation twice a year

    It's the cheapest donation available. Test a spring wave alongside the winter one.

    Measure: cost per reactivated donor

    A/B test significance in DAX

    Cost per Retained Donor =
DIVIDE (
    [Campaign Spend],
    [Retained Donors (Est.)]
)

Test Z Score =
VAR nA = CALCULATE ( SUM ( 'Reminder Test'[Appointments] ), 'Reminder Test'[Test Arm] = "Email only" )
VAR nB = CALCULATE ( SUM ( 'Reminder Test'[Appointments] ), 'Reminder Test'[Test Arm] = "SMS + email" )
VAR xA = nA - CALCULATE ( SUM ( 'Reminder Test'[Attended] ), 'Reminder Test'[Test Arm] = "Email only" )
VAR xB = nB - CALCULATE ( SUM ( 'Reminder Test'[Attended] ), 'Reminder Test'[Test Arm] = "SMS + email" )
VAR Pooled = DIVIDE ( xA + xB, nA + nB )    -- pooled no-show rate under H0
VAR StdErr = SQRT ( Pooled * ( 1 - Pooled ) * ( DIVIDE ( 1, nA ) + DIVIDE ( 1, nB ) ) )
RETURN
    DIVIDE (
        DIVIDE ( xA, nA ) - DIVIDE ( xB, nB ),
        StdErr
    )

Reduction 95% CI =
VAR nA = CALCULATE ( SUM ( 'Reminder Test'[Appointments] ), 'Reminder Test'[Test Arm] = "Email only" )
VAR nB = CALCULATE ( SUM ( 'Reminder Test'[Appointments] ), 'Reminder Test'[Test Arm] = "SMS + email" )
VAR pA = [No-show Rate: Email Only]
VAR pB = [No-show Rate: SMS + Email]
VAR Margin = 1.96 * SQRT ( DIVIDE ( pA * ( 1 - pA ), nA ) + DIVIDE ( pB * ( 1 - pB ), nB ) )
RETURN
    FORMAT ( ( pA - pB - Margin ) * 100, "0.0" ) & " to "
        & FORMAT ( ( pA - pB + Margin ) * 100, "0.0" ) & " pts"

    Limits of this analysis

    • All data is synthetic, so the size of each effect is illustrative. The method is what carries over.
    • Cost per returning donor needs 12 months of follow-up, so the newest campaigns can't be scored yet.
    • Campaign attribution is last-touch; a donor influenced by two campaigns counts once.
    • Reactivation lift compares campaign months with other months, not a randomised control.
