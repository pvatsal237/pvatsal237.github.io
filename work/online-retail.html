Are sales growing, and which customers matter most?

A UK online gift wholesaler's full invoice history, 1.07 million lines over two years. I cleaned and modelled it in SQL Server, segmented customers by how recently, how often and how much they buy, and built a Power BI report and a printable win-back list for the sales team.

Key findings

  1. Growth came from bigger orders, not more of them: net sales +5.7% while orders fell 4%.
  2. A small group carries the business: 1,303 Champions bring 70% of all customer spend.
  3. Only about 1 in 5 new customers orders again the next month, and 248 high-value customers have gone quiet.
01 · THE TREND

Sales grow slowly, with a sharp autumn peak

September to November brings more than a third of the year's sales. The forecast, built as a SQL Server view, expects about £10.3M over the next 12 months with the same autumn peak.

The United Kingdom is 85% of sales. Europe grew about 4%; the rest of the world nearly tripled but is still only 2%.

Net sales = goods sold less returns and cancellations. Postage, fees and manual adjustments are left out, and seven order-entry errors are flagged in SQL.

02 · WHO MATTERS

Seven in ten pounds come from one segment

Every customer gets a 1 to 5 score for how recently, how often and how much they bought, using NTILE in SQL. Champions score high on all three.

The 248 at-risk, high-value customers used to buy often or spend a lot and have gone quiet. A paginated SSRS report turns them into a call sheet the sales team can filter by country and print.

03 · RETENTION

Most new customers never come back

On average 21% of a month's new customers order again the next month, and about 18% are still buying a year later. The first cohort, December 2009, is the exception: long-standing trade customers who keep coming back.

On the product side, 1,037 of 4,706 products make 80% of sales, so the long tail is a candidate for range review.

Core measures (from the model)

Repeat Customer Rate =
VAR Buyers =
    ADDCOLUMNS ( VALUES ( 'Customer Month'[Customer ID] ), "@Orders", CALCULATE ( SUM ( 'Customer Month'[Orders] ) ) )
RETURN
    DIVIDE ( COUNTROWS ( FILTER ( Buyers, [@Orders] >= 2 ) ), COUNTROWS ( Buyers ) )

Retention % =
VAR Since = SELECTEDVALUE ( 'Customer Month'[Months Since First Order] )
VAR Active = CALCULATE ( DISTINCTCOUNT ( 'Customer Month'[Customer ID] ), REMOVEFILTERS ( 'Date' ) )
VAR CohortSize =
    CALCULATE (
        DISTINCTCOUNT ( 'Customer Month'[Customer ID] ),
        REMOVEFILTERS ( 'Date' ),
        REMOVEFILTERS ( 'Customer Month'[Months Since First Order] ),
        'Customer Month'[Months Since First Order] = 0
    )
RETURN
    IF ( Since >= 1 && Since <= 12, DIVIDE ( Active, CohortSize ) )

Share of Lifetime Spend =
DIVIDE ( SUM ( Customer[Lifetime Spend] ), CALCULATE ( SUM ( Customer[Lifetime Spend] ), REMOVEFILTERS ( Customer[Segment], Customer[Segment Order] ) ) )

Design

  • Its own theme: light page, charcoal header, coral accents, rounded panels and Trebuchet MS.
  • A different layout from the other reports: cards down the side, the forecast as the main chart, and the cohort heatmap leading page 2.

Limits of this analysis

  • Two years of history is short for a seasonal forecast; the range reflects that.
  • RFM is a ranking, not a prediction of who will stop buying.
  • Guest checkouts count in sales but not in customer measures.
