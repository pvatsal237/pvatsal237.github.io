How I work

Start from the decision

Every project opens with the question someone actually has to answer, and ends with a recommendation they can act on.

Show the uncertainty

Confidence intervals, sample sizes and data limits are on the page, not hidden in a footnote.

Build it to be maintained

Star-schema models, documented DAX measures and Power BI project files under version control, so the next analyst can pick it up.

Modern tooling, human judgement

At work I build Power BI models as code (PBIP, TMDL) and use AI-assisted development where it saves time, which cut model and report build time for our team. Every number I publish, I check myself.

About the data: projects use real public data where it exists (Ontario Health, Statistics Canada, UCI research datasets) and clearly labelled synthetic data where it doesn't. No employer or client data is used anywhere on this site.
