# Vatsal Patel | Business Intelligence & Analytics

Portfolio site: **https://pvatsal237.github.io**

Power BI case studies in healthcare, banking and non-profit. Each project page shows the report, the data model and the DAX behind it, and the analysis and recommendations.

| Project | Domain | Data |
|---|---|---|
| Ontario ED Wait Times | Healthcare | Real, Ontario Health public reporting |
| Bank Campaign Conversion | Banking | Real, anonymized (UCI Bank Marketing) |
| Donor Campaign Effectiveness | Non-profit | Synthetic, fictional organization |

The Power BI project files (PBIP) are in [`power-bi/`](power-bi). Unzip one and open the `.pbip` file in Power BI Desktop.

Data sources are credited on each project page.
