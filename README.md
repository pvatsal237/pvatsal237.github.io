# Vatsal Patel | Business Intelligence & Analytics

Portfolio site: **https://pvatsal237.github.io**

Power BI case studies in healthcare, banking, non-profit, public sector finance, HR, insurance, retail and BI governance. Each project page shows the report, the data model and the DAX behind it, and the analysis and recommendations.

| Project | Domain | Data |
|---|---|---|
| Ontario ED Wait Times | Healthcare | Real, Ontario Health public reporting |
| Bank Campaign Conversion | Banking | Real, anonymized (UCI Bank Marketing) |
| Donor Campaign Effectiveness | Non-profit | Synthetic, fictional organization |
| Federal Budget vs Actual Spending | Public sector | Real, Public Accounts of Canada (PSPC open data) |
| Workforce and First-Year Attrition | HR | Synthetic, fictional company; SQL Server script included |
| Claims Cost and Settlement Time | Insurance | Synthetic, fictional insurer; SQL Server model and forecast view |
| Online Retail Sales and Customers | Retail | Real, Online Retail II (UCI, CC BY 4.0); SQL Server model and SSRS report |
| Indicator Library | BI governance | Synthetic Power BI estate for a fictional utility; self-building catalogue of reports, models and indicators (live demo in `indicator-library/`) |

The Power BI project files (PBIP) are in [`power-bi/`](power-bi). Unzip one and open the `.pbip` file in Power BI Desktop.

Data sources are credited on each project page.
